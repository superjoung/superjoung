## About

상태와 실행 경로를 연결하는 게임 클라이언트 개발자 **정회륜**입니다.

Unity와 C#을 중심으로 전투·UI·입력·상태 수명주기를 구현해 왔습니다. 기능이 한 번 동작하는 것에서 끝내지 않고, **재진입·중단·반환 시점에도 같은 조건이 유지되는지**를 코드 경계와 검증 조건으로 설명하는 것을 중요하게 생각합니다.

```text
Problem → Design Choice → Runtime Path → Verification
```
